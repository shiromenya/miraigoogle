AI統合検索設定

Gemini API 設定

Google検索クエリの意図判定・レイアウト最適化を行うために Google Gemini API キーを入力してください。 キーはブラウザ内（chrome.storage.sync）にのみ安全に暗号化保存されます。

Google AI Studio で API キーを取得

取得 & 表示設定

ウェブ、ニュース、画像、動画、ショッピング各カテゴリから取得する最大件数です。
デフォルトでAntigravity統合モードを有効にする

検索結果アクセス時に自動的に統合フィードを表示します（ページ上のトグルで標準検索にいつでも切り替え可能）。

Webサイトのプレビューサムネイルを表示する

Webサイトの検索結果カードに、サイトのスクリーンショットまたはサムネイル画像を表示します。

フォールバックモード（APIキー未設定時）

APIキーが設定されていない場合でも、独自のヒューリスティック分析によって自動統合フィードを生成します。
